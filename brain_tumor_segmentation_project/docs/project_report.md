# 项目报告：跨模态互补的脑肿瘤分割教学项目

## 1. 项目背景

脑肿瘤分割是医学影像分析中的典型任务。对于脑部 MRI 来说，不同序列在病灶显示上存在明显互补性：T1 更适合观察解剖结构，T1ce 更容易突出增强区域，T2 和 FLAIR 对水肿范围更敏感。因此，将多个 MRI 序列联合建模，是脑肿瘤自动分割的重要思路。

本项目面向本科生教学场景，目标不是追求复杂创新，而是构建一个 **可理解、可复现、可运行** 的最小完整项目，用于支撑毕业设计中的选题、实验和论文写作。

## 2. 项目目标

本项目的主要目标如下：

1. 建立一个能够读取多模态 MRI 的分割流程；
2. 使用 2D U-Net 作为稳妥基线完成 WT 二分类分割；
3. 在基线之上加入一个轻量模态门控模块，实现“跨模态互补”这一论文核心表达；
4. 提供 toy 数据、真实数据预处理脚本、训练脚本与预测脚本，形成完整闭环。

## 3. 技术路线

整体流程如下：

1. 输入多模态 MRI（T1 / T1ce / T2 / FLAIR）；
2. 进行标准化、裁剪和 2D 切片；
3. 通过 baseline U-Net 或 gate U-Net 进行训练；
4. 使用 Dice + BCE 作为损失函数；
5. 通过 Dice、IoU 评估模型分割效果；
6. 对单病例进行预测并保存掩膜。

## 4. 模型设计

### 4.1 Baseline U-Net

基线模型采用标准 2D U-Net。它把 4 个 MRI 序列当作 4 个输入通道，通过编码器提取特征，再经过解码器恢复空间分辨率，最终输出一张肿瘤区域概率图。

### 4.2 Gate U-Net

为了体现“跨模态互补”，本项目设计了一个轻量 `ModalityGate` 模块。其基本思想是：

- 对 4 个模态做全局池化；
- 通过小型 MLP 生成每个模态的权重；
- 用该权重对输入特征进行重标定；
- 再将加权后的特征送入 U-Net。

这种方式虽然简单，但很适合作为本科毕设中的“轻量改进”，既容易实现，也容易解释。

## 5. 数据集设计

### 5.1 Toy 数据集

为了方便零基础同学练手，项目提供 `generate_toy_dataset.py`。它会自动生成 4 模态假 MRI 图像和对应的肿瘤掩膜，从而帮助学生在不依赖真实医学数据的情况下，先跑通“数据生成 → 模型训练 → 指标输出”的完整流程。

### 5.2 BraTS 数据集

真实实验建议使用 BraTS 数据集。项目中的 `prepare_brats_slices.py` 可以把原始 `.nii.gz` 文件整理成 2D 切片 `.npz` 文件，降低训练门槛并简化数据读取逻辑。

## 6. 关键实现说明

### 6.1 数据读取

`dataset.py` 负责读取 `.npz` 文件，并返回：

- `image`：4 通道 MRI 图像；
- `mask`：单通道 WT 掩膜；
- `case_id` 与 `slice_idx`：便于追踪切片来源。

### 6.2 损失函数

项目使用 Dice + BCE 的组合损失。一方面，BCE 负责稳定训练；另一方面，Dice 能更好应对分割任务中的类别不平衡问题。

### 6.3 训练脚本

`train.py` 完成以下工作：

1. 读取 train / val / test 划分；
2. 构建模型、优化器和损失函数；
3. 逐 epoch 训练与验证；
4. 保存验证集 Dice 最优的模型；
5. 输出测试指标和训练曲线。

### 6.4 预测脚本

`predict_case.py` 用于对单个 BraTS 病例执行预测，并输出 NIfTI 掩膜结果，便于后续可视化和答辩展示。

## 7. 适合本科毕业论文的原因

本项目有以下几个优点：

1. **难度可控**：采用 2D U-Net 和 WT 二分类，避免了 3D 大模型带来的显存和调参压力；
2. **创新点适中**：增加轻量 gate 模块即可支撑“跨模态互补”表达；
3. **流程完整**：包含数据、模型、训练、预测与文档，适合做毕业设计；
4. **易于写作**：方法、实验和结论都容易组织成论文结构。

## 8. 建议实验方案

建议最少完成以下实验：

1. `baseline` 与 `gate` 的性能对比；
2. 用 toy 数据先验证流程可跑通；
3. 用少量 BraTS 病例进行真实训练；
4. 展示 3~5 张切片级可视化结果。

## 9. 总结

本项目以“跨模态互补的脑肿瘤分割”为主题，提供了一套适合本科生使用的完整教学实现。通过 baseline U-Net 与 gate U-Net 的对比，学生可以较直观地理解什么是多模态 MRI、什么是特征互补、以及如何把这些概念落地为一个真正能运行的项目。
